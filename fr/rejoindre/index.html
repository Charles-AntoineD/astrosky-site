Comment rejoindre AstroSky

AstroSky tourne sur Minecraft: Java Edition 26.2, sur ordinateur (Windows, macOS, Linux). L’édition Bedrock (consoles, téléphones, tablettes) ne peut pas s’y connecter.

Adresse du serveur

astrosky.gg

Minecraft: Java Edition 26.2 · Java seulement, pas Bedrock · Pour les 18 ans et plus

Ouverture le lundi 16 novembre 2026, à 18 h, heure du Québec. D’ici là, le serveur est fermé aux joueurs (liste blanche).

Avant de commencer

  • Minecraft: Java Edition, sur ton propre compte Microsoft.
  • Avoir 18 ans ou plus : AstroSky est réservé aux 18 ans et plus.

Rejoindre en quatre étapes

  1. Ouvre le Minecraft Launcher et choisis Minecraft: Java Edition.

  2. Utilise la version 26.2. Si le launcher lance une autre version : Installations → Nouvelle installation, choisis la version 26.2, clique sur Créer, puis sur Jouer.

  3. Dans le jeu : Multijoueur → Ajouter un serveur. Nom du serveur : AstroSky. Adresse du serveur : astrosky.gg. Clique sur Terminé.

  4. Choisis AstroSky dans la liste et clique sur Rejoindre le serveur. En jeu, tape /ob pour aller sur ton île et /help pour l’aide.

Facultatif : un pack de ressources

AstroSky fonctionne avec les textures de base de Minecraft. Si tu veux, les packs de ressources qu’on conseille soignent le ciel de nuit. Le serveur ne t’envoie rien.

Si ça ne marche pas

  • Un message qui dit que tu n’es pas sur la liste blanche : le serveur n’est pas encore ouvert. Reviens le 16 novembre 2026, à 18 h, heure du Québec.
  • « Outdated client » ou « Outdated server » : ta version ne correspond pas. Utilise 26.2 (étape 2).
  • « Can’t resolve hostname » ou « Can’t connect to server » : vérifie l’adresse, astrosky.gg, sans www ni port, puis réessaie dans quelques minutes.
  • « Failed to log in » ou « Invalid session » : ferme le jeu, relance le Minecraft Launcher et reconnecte-toi.

Ça bloque encore ? Écris-nous depuis la page de contact (objet « Support ») avec ton pseudo Minecraft et le message d’erreur exact.
