How to join AstroSky

AstroSky runs on Minecraft: Java Edition 26.2, on computers (Windows, macOS, Linux). Bedrock Edition (consoles, phones, tablets) can’t join.

Server address

astrosky.gg

Minecraft: Java Edition 26.2 · Java only, no Bedrock · For players 18 and over

Opens Monday, November 16, 2026, at 6 p.m. Eastern Time (Québec time). Until then, the server is closed to players (whitelist).

Before you start

  • Minecraft: Java Edition, on your own Microsoft account.
  • Being 18 or over: AstroSky is for players 18 and over.

Join in four steps

  1. Open the Minecraft Launcher and choose Minecraft: Java Edition.

  2. Use version 26.2. If the launcher starts another version: Installations → New installation, pick version 26.2, click Create, then Play.

  3. In the game: Multiplayer → Add Server. Server Name: AstroSky. Server Address: astrosky.gg. Click Done.

  4. Select AstroSky in the list and click Join Server. In game, type /ob to reach your island and /help for help.

Optional: a resource pack

AstroSky works with the default Minecraft textures. If you like, the resource packs we recommend polish the night sky. The server sends you nothing.

If it doesn’t work

  • A message saying you are not on the whitelist: the server isn’t open yet. Come back on November 16, 2026, at 6 p.m. Eastern Time.
  • “Outdated client” or “Outdated server”: your version doesn’t match. Use 26.2 (step 2).
  • “Can’t resolve hostname” or “Can’t connect to server”: check the address, astrosky.gg, with no www and no port, then try again in a few minutes.
  • “Failed to log in” or “Invalid session”: close the game, restart the Minecraft Launcher and sign in again.

Still stuck? Write to us from the contact page (subject "Support") with your Minecraft username and the exact error message.
